# Trip Tracker

A RuneLite plugin that enhances loot tracking with trip scoping. Group your drops by grinding session so you can see exactly what you earned per trip.

## Features

### Three View Modes

- **List View** — Every drop shown individually with NPC name, combat level, items, and GE values
- **Grouped View** — Loot aggregated by NPC across all kills
- **Trip View** — Scope your loot to named trips for per-session tracking

### Trip Management

- Create trips to track loot for a specific grinding session
- See trip stats at a glance: start time, duration, total kills, and GP earned
- Stop trips when you're done (data persists for the session)
- Delete old trips you no longer need
- Only one trip can be active at a time

### Pickpocket Tracking

- Automatically detects and tracks pickpocket loot
- Coin pouches are converted to estimated GP values based on the NPC

### UI

- Collapsible drop panels — click to expand or collapse details
- Items sorted by value within each drop
- Large values shortened (10k, 1.5m, 2.1b)
